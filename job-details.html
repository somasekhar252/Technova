Role Overview

Senior Full Stack Engineer

TechNova is seeking an experienced Senior Full Stack Engineer to join our core Web Engineering Pod. In this role, you will lead the technical design, backend API development, and frontend execution for enterprise client portals and SaaS products.

Key Responsibilities

  • ✓ Architect, build, and maintain scalable web applications using React, Node.js, and PostgreSQL.
  • ✓ Design clean RESTful and GraphQL APIs with robust security authentication layers.
  • ✓ Collaborate with UI/UX designers to translate Figma wireframes into high-performance web components.
  • ✓ Participate in 2-week sprint planning, code reviews, and technical mentorship of junior engineers.
  • ✓ Write automated unit and integration tests to ensure 90%+ test coverage.

Required Technical Skills

  • ✓ 4+ years of professional full-stack software development experience.
  • ✓ Deep proficiency in JavaScript (ES6+), React.js, and Node.js ecosystems.
  • ✓ Strong relational database design skills (PostgreSQL or MySQL) and query optimization.
  • ✓ Experience with Docker containerization and AWS cloud service deployment.
